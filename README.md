# Sae Park Hub (SPH)

Prototipe website penjualan dan promosi wisata untuk Sae Park.
Esai PELITA 2026, MAN 3 Sleman, Kelompok Sae Park.

Foto, harga, jam buka, dan nomor WhatsApp di prototipe ini masih contoh.

## Struktur
- `index.html` : seluruh website (HTML, CSS, JS dalam satu file)
- `img/` : logo dan wireframe dari esai

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages
(Settings > Pages > Branch `main` > folder `/ (root)`).
